# Repositorio .NET

Este repositorio reúne varios proyectos de práctica desarrollados en C# y ASP.NET Core para aprender fundamentos, programación orientada a objetos y desarrollo web básico.

## Contenido del repositorio

- Ejercicios: ejercicios básicos de programación en C#.
- Listas: práctica con colecciones y listas.
- Personas: ejercicios con clases y objetos relacionados con personas y animales.
- POO: introducción a la programación orientada a objetos.
- POO2: continuación de conceptos de POO.
- Proyecto MVC: aplicación ASP.NET Core MVC básica.
- taller_3: taller de práctica con ejercicios aplicados en C#.

## Requisitos previos

- .NET SDK instalado
- Visual Studio Code o Visual Studio
- Terminal de PowerShell o CMD

## Cómo empezar

### 1. Entrar a la carpeta del proyecto que quieras ejecutar

```powershell
cd .\Ejercicios
```

### 2. Restaurar dependencias

```powershell
dotnet restore
```

### 3. Compilar el proyecto

```powershell
dotnet build
```

### 4. Ejecutar la aplicación

```powershell
dotnet run
```
