# Ejercicios

Este proyecto reúne ejercicios básicos de C# para practicar conceptos fundamentales de programación.

## Qué aprendí

- estructuras básicas del lenguaje C#
- clases, objetos y métodos
- uso de propiedades y lógica de negocio sencilla
- organización de un proyecto de consola

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\Ejercicios\Ejercicios.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\Ejercicios\Ejercicios.csproj
```

Si prefieres, también puedes abrir la solución `Ejercicios.sln` en Visual Studio.
