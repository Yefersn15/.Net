# Proyecto MVC

Este proyecto es una aplicación ASP.NET Core MVC que muestra cómo estructurar una solución con modelos, vistas, controladores y lógica de negocio.

## Qué aprendí

- creación de un proyecto MVC con ASP.NET Core
- uso de controladores y vistas
- organización de modelos para representar datos
- conexión básica de la aplicación con lógica de negocio
- estructura inicial para expandir el proyecto con más funcionalidades

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\Proyecto MVC\Proyecto MVC.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\Proyecto MVC\Proyecto MVC.csproj
```

5. Abre la URL que aparece en la terminal, normalmente:

```text
http://localhost:5000
```

También puedes abrir la solución `Proyecto MVC.sln` en Visual Studio.
