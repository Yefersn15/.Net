# POO2

Proyecto complementario para profundizar en conceptos de programación orientada a objetos.

## Qué aprendí

- reutilización de clases
- diseño más limpio de objetos
- implementación de comportamientos con métodos
- práctica adicional de abstracción y organización de código

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\POO2\POO2.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\POO2\POO2.csproj
```

También puedes abrir la solución `POO2.sln` en Visual Studio.
