# POO

Proyecto orientado a practicar programación orientada a objetos en C#.

## Qué aprendí

- conceptos de clase, objeto e instancia
- herencia y encapsulación
- relaciones entre clases
- diseño básico de modelos de negocio

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\POO\POO.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\POO\POO.csproj
```

También puedes abrir la solución `POO.sln` en Visual Studio.
