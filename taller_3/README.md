# Taller 3

Este proyecto corresponde a un taller de práctica en C# donde se trabajan ejercicios relacionados con clases, objetos y lógica de programación aplicada.

## Qué aprendí

- organización de código en clases reutilizables
- uso de objetos para representar entidades del negocio
- lógica básica para resolver problemas prácticos
- compilación y ejecución de proyectos de consola en .NET

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\taller_3\taller_3.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\taller_3\taller_3.csproj
```

También puedes abrir la solución `taller_3.sln` en Visual Studio.
