# Personas

Proyecto simple para practicar el uso de clases, objetos y relaciones entre entidades en C#.

## Qué aprendí

- creación de clases y objetos
- encapsulación básica
- uso de propiedades y métodos
- representación de datos de personas y animales

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\Personas\Personas.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\Personas\Personas.csproj
```

También puedes abrir la solución `Personas.sln` en Visual Studio.
