# Listas

Proyecto de práctica para trabajar con listas y estructuras de datos en C#.

## Qué aprendí

- manejo de colecciones en C#
- uso de listas dinámicas
- recorrido de datos con `for` y `foreach`
- lógica básica para almacenar y consultar información

## Cómo iniciar este proyecto

1. Abre una terminal desde esta carpeta.
2. Restaura dependencias:

```powershell
dotnet restore
```

3. Compila el proyecto:

```powershell
dotnet build .\Listas\Listas.csproj
```

4. Ejecuta la aplicación:

```powershell
dotnet run --project .\Listas\Listas.csproj
```

También puedes abrir la solución `Listas.sln` en Visual Studio.
